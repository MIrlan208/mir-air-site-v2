# МИР×АИР: сайт-витрина студенческой команды

Сайт группы первокурсников МИР×АИР (МИР-1, МИР-2, МИР-3): достижения, проекты (портфолио) и банк идей (Telegram-бот), составы групп, новости и фото. Живая работа команды идёт в Telegram, а сайт показывает результат руководству, работодателям, партнёрам и новым участникам.

## Возможности

- Главная: о команде, группы, достижения, банк идей, лучший проект, новости, галерея и видео, блок «Поддержать команду».
- Раздел «Проекты» с поиском и фильтрами по группе, типу и статусу. Проекты смешанных команд (`groups: ["mir-1","mir-2"]`) показываются в каждой своей группе.
- «Банк идей»: ссылка и QR на Telegram-бота (`SITE.bot` в `data.js`).
- Страница проекта `#p-<id>`: проблема, решение, результат, как работает, из чего собрано, команда, планы, код. Пустые блоки не показываются.
- Страницы групп `#mir-1`, `#mir-2`, `#mir-3` со статистикой и составом по отрядам и командам.
- Адаптивная вёрстка (ПК, планшет, телефон), тема «Чертёж» (синяя сетка, жёлтый акцент).

## Стек

HTML, CSS и чистый JavaScript без фреймворков и зависимостей. Данные лежат в обычных JS-файлах. Шрифты IBM Plex (Google Fonts). Node.js 18+ нужен только для проверки и сборки.

## Структура

```
index.html        разметка главной страницы
style.css         стили (тема «Чертёж»)
script.js         логика: маршруты по хэшу, фильтры, страницы групп и проектов
data.js           настройки сайта (ссылка Telegram, всего человек) и составы групп
bank.js           банк идей и проектов, достижения
img/, media/      фотографии и видео
scripts/build.mjs проверка и сборка в dist/
```

## Запуск

Сайт статический, можно просто открыть `index.html` или поднять локальный сервер:

```bash
npm run dev          # http://localhost:8080
# или без Node:
python3 -m http.server 8080
```

## Сборка

```bash
npm run build
```

Скрипт проверяет синтаксис JS, наличие всех файлов из `img/` и `media/`, уникальность `id` проектов и копирует сайт в `dist/`. Если есть ошибка, сборка останавливается и называет файл. Предпросмотр: `npm run preview`.

## Деплой

- **GitHub Pages**: Settings → Pages → Source: *GitHub Actions*. Workflow `.github/workflows/pages.yml` соберёт и опубликует сайт при каждом push в `main`.
- **Свой сервер (Nginx)**: скопируй содержимое `dist/` в папку сайта, например `rsync -av dist/ user@server:/var/www/mir-air/`.
- Любой статический хостинг (Cloudflare Pages, Netlify): команда сборки `npm run build`, папка публикации `dist`.

## Как добавить проект

1. Положи фото в `img/` (до 1100 px по длинной стороне, JPEG).
2. Скопируй блок проекта в `bank.js` и измени поля. Подсказки по полям (`id`, `photos`, `story`) в комментарии в начале файла.
3. Поля `story` необязательны: что не заполнено, на странице не показывается.
4. Запусти `npm run build`: он поймает опечатку в пути к фото или повторяющийся `id`.

## Что заменить перед публикацией

- `data.js`: `SITE.telegram` сейчас заглушка `https://t.me/your_group`.
- `index.html`: куратор, почта и телефон в блоке «Поддержать команду», суммы («уточнить»).
- `bank.js`: записи с `example: true` это примеры, удали их по мере появления настоящих.
- Согласие участников на публикацию ФИО в составах групп.
